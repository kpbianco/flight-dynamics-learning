## Implemented model contract

Public inputs:

- speed-feedback gain in `[0,0.3] 1/s`, baseline `0.15 1/s`;
- normalized-throttle time constant in `[0.2,1.4] s`, baseline `0.8 s`;
- feedback sign `+1` for correct command-minus-speed feedback or `-1` for the deliberately broken
  reversed case.

Fixed declarations:

- true airspeed starts at `60 m/s`; command changes to `70 m/s` at `1 s`;
- level-flight drag is
  `D(V)=0.5 rho S CD0 V^2 + 2 k W^2/(rho S V^2)` with
  `rho=0.736115547399152 kg/m^3`, `S=16.2 m^2`, `CD0=0.025`, `k=0.045`,
  `m=1200 kg`, `g=9.80665 m/s^2`, and `CLmax=1.4`;
- requested acceleration is `s K_V (V_command-V)` and unclamped thrust command is current drag
  plus mass times requested acceleration;
- thrust command is saturated to `[0,4000] N` and normalized throttle command to `[0,1]`;
- delivered throttle obeys `delta_dot=(delta_command-delta)/tau_T`, delivered thrust is
  `4000 delta`, and `V_dot=(T-D)/m`;
- fixed-step forward Euler uses `0:0.02:30 s`, exactly 1501 samples and 1500 updates;
- the declared stall boundary is `37.546671093409294 m/s`; all accepted public corners remain
  above it over the fixed horizon;
- no integral state, persistent/global state, input-sized allocation, random source, external I/O,
  opaque control/optimization solver, asynchronous work, or background resource.

The current-drag feedforward is exact only inside this teaching model. It is not evidence that a
real controller knows drag exactly. The normalized first-order throttle is not an identified
engine or fuel-flow response. The lower time constant is bounded so the explicit throttle update
fraction is at most `0.1` per step over the accepted domain.

Broken `model(0.15,0.8,-1)` references:

- correct and broken state histories match through the command sample;
- the `+10 m/s` proper error becomes `-10 m/s` controller-used error, raw requested thrust is
  `-973.0478274094974 N`, and saturation commands exactly idle throttle at onset;
- throttle command remains idle and thrust request remains lower-saturated after onset;

This is positive feedback created by reversing only the speed-error sign. Idle saturation prevents
negative thrust but does not restore speed. It is not integrator windup because the model has no
integrator state. The final-second result establishes continued failure only through the fixed
observed horizon; it is not an infinite-horizon or post-stall proof. A correct call after the
broken or any rejected call reproduces baseline exactly.
