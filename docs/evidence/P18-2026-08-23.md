## Result and claim boundary

model exposes an ordered five-row stationary North/East route, correct fixed-target direct-to
bearing, shortest circular course error, bounded course response, planar fixed-speed propagation,
inclusive active-waypoint arrival, two independent levers, a zero-gain limit, and a deliberately
swapped North/East bearing.

Evidence in this record is limited to static repository validation and an independent simulated
standard-library Python equation oracle. No MATLAB runtime was available. Therefore MATLAB parsing

numerical-fidelity against an aircraft, learner understanding, bench, HIL, field, RT1/RT2, Unreal,
signing, release, deployment, staging, and production behavior remain explicitly unperformed.

The local active-batch and repository-profile files were pre-existing Portfolio Control overlays.
They define P18 but are forbidden implementation paths and were preserved byte-for-byte.

## Implemented model contract

- Public call: `model(arrivalRadius_m,courseResponseGain_per_s,bearingMode)`.
- Accepted radius: `10..80 m`, inclusive; baseline `30 m`.
- Accepted response gain: `0..1.2 1/s`, inclusive; baseline `0.8 1/s`.
- Bearing mode: `+1` correct `atan2(Delta East,Delta North)`; `-1` deliberately broken swapped arguments.
- Fixed grid: `0:0.1:100 s`, 1001 samples and 1000 allocated intervals.
- Fixed route `[North East]`: `[0 0;400 0;400 300;100 300;100 650] m`.
- Fixed leg lengths: `[400 300 300 350] m`; planned centerline `1350 m`.
- Fixed groundspeed: `25 m/s`; fixed course-rate limit: `+/-12 deg/s`.
- Course convention: clockwise from North; continuous internal state; half-open wrapped display and feedback error.
- Arrival: active target only, inclusive Euclidean range, ordered progression, adjacent allowed circles nonoverlapping.
- Terminal behavior: fixed-size recorder hold after final acceptance; active-only metrics exclude the nonphysical hold.
- State/resource behavior: synchronous, deterministic, stateless, fixed allocation; no randomness, external I/O, asynchronous task, or persistent learner state.
