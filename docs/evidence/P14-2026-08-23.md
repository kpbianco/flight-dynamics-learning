## Implemented model contract

Public inputs:

- heading-to-bank gain in `[0,1] rad/rad`, baseline `0.5 rad/rad`;
- closed-loop teaching roll natural frequency in `[1.2,3.6] rad/s`, baseline `2.4 rad/s`;
- heading-error mode `1` for wrapped shortest-path feedback or `0` for deliberately broken raw
  displayed-angle subtraction.

Fixed declarations:

- continuous heading starts at `+170 deg`; displayed command changes to `-170 deg` at `1 s`, with
  nearest continuous target `+190 deg` and shortest command step `+20 deg`;
- `wrap(x)=mod(x+pi,2*pi)-pi` on the half-open interval `[-pi,pi)`;
- raw error is displayed command minus wrapped display heading; correct controller error wraps that
  result, while the broken mode alone selects the raw value;
- outer command `phi_c=sat(K_psi e_psi,+/-12 deg)`;
- inner roll response `phi_dot=p_phi` and
  `p_phi_dot=omega_phi^2(phi_c-phi)-2 zeta_phi omega_phi p_phi`, with fixed
  `zeta_phi=0.8`;
- coordinated level turn `psi_unwrapped_dot=g tan(phi)/V`, with `g=9.80665 m/s^2` and fixed
  `V=60 m/s`; `tan` receives radians;
- positive bank is right-wing-down and positive heading is nose-right; `p_phi` is the bank
  Euler-angle rate in the declared approximation, not a general body-axis rate;
- explicit forward-Euler grid `0:0.02:60 s`, exactly 3001 samples and 3000 updates;
- bank-command limit `12 deg` and checked accepted-domain actual-bank teaching envelope `15 deg`;
- no persistent/global state, input-sized allocation, asynchronous work, external I/O, or opaque
  control/toolbox solver.

The bank-command bound does not itself mathematically bound actual bank; the independent accepted
corner/grid checks establish the stated `15 deg` envelope only over this public input domain and
fixed horizon. The turn relation assumes coordinated level flight, still air, exact state, and
unmodeled energy support for fixed speed.
