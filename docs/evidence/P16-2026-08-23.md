## Implemented model contract

Public inputs:

- true airspeed in `[45,75] m/s`, baseline `60 m/s`;
- air density in `[0.5,1.5]*0.736115547399152 kg/m^3`, baseline the reference density;
- schedule mode `+1` for actual dynamic-pressure lookup, `0` for fixed reference gains, or `-1`
  for the deliberately broken true-airspeed-only lookup.

Fixed declarations:

- `qbar=0.5*rho*V^2`, `qbar_ref=1325.0079853184736 Pa`, and plant effectiveness
  `b=12*(qbar/qbar_ref) 1/s^2`;
- table ratios `[0.5,0.75,1,1.25,1.5]`, target natural frequency `2.4 rad/s`, and target damping
  ratio `0.8`;
- angle-gain knots `[0.96,0.64,0.48,0.384,0.32] rad/rad` and rate-gain knots
  `[0.64,0.4266666667,0.32,0.256,0.2133333333] s`;
- manual ordered bracketing, linear interpolation, and endpoint hold without changing the actual
  plant condition;
- controller `delta_a=sat(K_phi*(phi_command-phi)-K_p*p,+/-15 deg)`;
- plant `phi_dot=p`, `p_dot=b*delta_a`, with positive roll, rate, and equivalent aileron
  right-wing-down;
- a `0` to `10 deg` command at `0.5 s` on `0:0.01:8 s`, exactly 801 samples and 800 forward-Euler
  updates;
- no input-sized allocation, persistent/global state, random source, external I/O, opaque
  control/optimization solver, asynchronous work, or background resource.

At a table knot, substitution gives
`phi_ddot+2*zeta*omega_n*phi_dot+omega_n^2*phi=omega_n^2*phi_command` while the command is
unsaturated. Linear interpolation approximates the reciprocal gain curve between knots. Endpoint
hold bounds lookup but does not prove safety outside the table.
