# Start here

This is the Flight Dynamics and Aerospace GNC interactive MATLAB track. Run `./bin/learn status`, then
`./bin/learn start`. P01 is the reference slice, P02 is the implemented aerospace-frame lesson, and
`curriculum/modules.json` records the current contiguous implementation frontier as later modules
advance through one-to-one Portfolio Control batches. A learner session follows read → visualize →
move one lever → visualize the change → read/explain, then a broken case, checks, and teach-back.

Use `docs/CURRICULUM_AUDIT.md` for the complete phase and batch map.
